🔧 敲盆宠物 · 独立预览

这个页面不依赖 DSH，直接加载 lib/client.js 本体。
右下角就是它 —— 先点它（或者它头上的铁盆），再点下面的「模拟执行出错」。

能试出来的东西：
→ 点「开始任务」：它开始摇摆唱歌，飘音符（真实 DSH 里是 agent 一干活就唱）
→ 点它或它头上的盆：抖一下 + 冒台词，饱食度掉 12
→ 连敲 3 下：它跑去讨白饭（左边出现一碗饭）
→ 连敲 6 下：开始阴阳你
→ 点那碗饭：它跑过来吃掉
→ 拖拽：能挪位置，位置会记住
→ 鼠标悬停在它身上：显示饱食度条 + 计数器

关于素材：这个页面会加载你真实的素材 —— 直接双击 demo.html 时读不到（浏览器不给本地网页读别的目录）， 请用 node tools/serve-demo.js 起一个本地预览， 它会把你放在 ~/.dsh/bonk-pet/ 的歌和图喂进来。
唯一没有的是 DSH 的事件流：真实界面里 agent 一干活它就唱、 一出错就掉钢管，这里靠上面的按钮手动触发。
